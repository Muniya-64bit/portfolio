# Isurumuni Wijesooriya — portfolio

Personal site: backend and cloud engineer, CSE undergraduate at the University of Moratuwa.

A single static page (`index.html`) styled as a terminal README, with no build step.
Animations use [Anime.js](https://animejs.com) 4 from a CDN: a typed `whoami`, scroll
reveals, and a live AWS-topology network in the background. They switch off for
visitors who prefer reduced motion.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
